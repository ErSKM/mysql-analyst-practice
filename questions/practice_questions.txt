MYSQL ANALYST PRACTICE — RETAIL DATASET
=============================================

Dataset size:
- 30,000 customers
- 800 products
- 40 stores
- 220 employees
- 100,000 orders
- 300,000+ order lines
- payments + returns
- orders cover 2024-01-01 to 2026-08-31

Core business calculations:
Line Gross = quantity * unit_price
Discount = quantity * unit_price * discount_pct / 100
Line Net Revenue = Line Gross - Discount
Approx Margin = Line Net Revenue - quantity * products.unit_cost

Default rules:
- Revenue questions use Completed orders unless stated otherwise.
- Do not count order_items as orders.
- Use COUNT(DISTINCT customer_id) for unique customers.
- Be careful about duplicate multiplication when joining order-level and line-level tables.
- Define the output grain before writing the query.

Suggested workflow:
1. Read the question.
2. State the output grain.
3. Identify tables and join keys.
4. Identify filters.
5. Decide aggregation level.
6. Choose JOIN / subquery / CTE / window function.
7. Write and test.
8. Only ask for the solution if stuck.
